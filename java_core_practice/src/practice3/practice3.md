Practice 3
The police sector needs to manage the means of transport including: cars,motorbikes, trucks. Each category includes information: vehicle number,manufacturer, year of manufacture, vehicle color and vehicle owner.
In there:
– Cars manage more attributes: number of seats, engine type.
– Motorcycles manage more attributes: capacity.
– Trucks manage more attributes: tonnage.
– Vehicle owners manage information: cmnd number, full name, email.
With your OOP knowledge learned, write a program in the Java programminglanguage that fulfills the following requirements:

Requirement 1: Build classes to manage the above facilities effectively.

Requirement 2: The program performs the following tasks:

1.  More means of transport
2.  Search for transport by vehicle number
3.  Find the vehicle owner's vehicle with the corresponding cmnd number.
4.  Delete all vehicles of any manufacturer.
5.  Indicate which manufacturer has the most vehicles under management
6.  Sort vehicles by number of vehicles in descending order
7.  Statistics of each vehicle type, how many vehicles are being managed.
